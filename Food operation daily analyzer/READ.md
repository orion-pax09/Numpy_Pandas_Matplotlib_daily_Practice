# Food Delivery Data Analyzer 🚴

## Overview
A Python data analysis project that explores food delivery performance using NumPy and Pandas.

The project analyses delivery times, traffic conditions, missing values, and unusual delivery records.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Features
- Dataset exploration
- Duplicate detection and removal
- Missing value handling
- Statistical analysis
- Traffic-based delivery analysis
- Outlier detection using IQR
- Delivery time visualization using box plots

## Key Findings
- High traffic has the longest average delivery time.
- Low traffic has the shortest average delivery time.
- An unusually long delivery was identified using IQR.
- Missing values were handled using median imputation.
