# Customer Revenue Analysis with Pandas & Matplotlib

## Project Overview

This project focuses on analyzing customer purchasing behavior and sales performance using Python, Pandas, NumPy, and Matplotlib.

The goal was to explore sales data, calculate revenue, identify high-value customers, and understand how different product categories contribute to total revenue.

## Technologies Used

- **Python** – Core programming language
- **Pandas** – Data manipulation, grouping, aggregation, and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Jupyter Notebook** – Interactive development and analysis

## Key Tasks Performed

- Calculated total price for each order using quantity and unit price.
- Grouped sales data by customer ID.
- Calculated total revenue generated by each customer.
- Identified the highest-spending customer using `idxmax()`.
- Used `agg()` for multiple aggregations, including total revenue and customer details.
- Explored Pandas pivot tables to summarize sales data.
- Grouped orders by product category to calculate total revenue.
- Created bar charts using Matplotlib to visualize revenue by category.

## Data Analysis Concepts Practiced

- `groupby()`
- `agg()` and named aggregation
- `sum()` and `mean()`
- `idxmax()` and `max()`
- `loc[]` for row selection
- `sort_values()`
- `pivot_table()`
- Matplotlib bar charts

## Visualization

The project includes a bar chart showing total revenue generated by each product category, making it easier to compare category-wise sales performance.
