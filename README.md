# NumPy, Pandas & Matplotlib Daily Practice

A collection of hands-on Python projects and daily exercises focused on learning and practicing **NumPy, Pandas, and Matplotlib** through real-world datasets and practical data analysis tasks.

## Projects

### 1. Food Operation Daily Analyzer
Analyzes food delivery data to explore delivery performance, traffic conditions, weather impact, missing values, and statistical insights.

**Tools:** Python, NumPy, Pandas, Matplotlib

### 2. SpendSense
A personal expense analysis project that explores spending patterns and provides insights through data manipulation and visualization.

**Tools:** Python, NumPy, Pandas, Matplotlib

### 3. E-commerce Revenue & Customer Analytics
Analyzes e-commerce sales data to understand customer purchasing behavior, category-wise revenue, and customer spending patterns. Uses grouping, aggregation, pivot tables, and data visualization to extract business insights.

**Tools:** Python, Pandas, NumPy, Matplotlib , Jupyter Notebook

### 4. Library Reorder Risk Analyzer
Analyzes library inventory data to identify books that may require restocking and explore inventory levels, reorder risks, and stock management insights.

**Tools:** Python , Pandas , NumPy, Matplotlib , Jupyter Notebook

## Learning Goals

- NumPy arrays and numerical operations
- Pandas DataFrames and data cleaning
- Filtering, grouping, and aggregation
- Handling missing and duplicate values
- Descriptive statistics and quartiles
- Data visualization using Matplotlib
- Working with real-world and messy datasets
