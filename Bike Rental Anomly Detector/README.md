Bike Rental Anomaly Detection

Analyzed bike rental data using Python, NumPy, Pandas, and Matplotlib.

- Calculated mean, median, standard deviation, and IQR.
- Detected outliers using the IQR method.
- Used Boolean filtering to isolate abnormal rental values.
- Compared statistical measures before and after removing outliers.
- Visualized the data using plots and a boxplot.

Key finding: An extreme rental value significantly affects the mean and standard deviation, demonstrating why outlier detection is important during data preprocessing.
